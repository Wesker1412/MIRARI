# 一、現象：角鬥為什麼常常沒有打到底

許多動物的衝突看起來更像儀式，而不像戰爭。

紅鹿在繁殖季爭奪配偶時，往往先互相吼叫，再並肩平行行走，彼此打量體型。很多對峙在這個階段就結束了，較弱的一方自行離開。響尾蛇雄性相鬥時互相纏繞、試圖把對方壓倒在地，卻很少動用毒牙。

早期的行為學家常把這種克制解釋為「對物種有利」：如果每次爭端都打到你死我活，整個族群會蒙受損失。問題在於，天擇作用在個體與基因上，而不是作用在物種的整體福祉上。一個肯冒險下重手的突變個體，只要能搶到更多資源，就會留下更多後代，所謂的「物種利益」擋不住它擴散。

所以真正的問題是：在每個個體都只顧自己的前提下，克制還能不能穩定存在？

# 二、思想實驗：一片只有鷹與鴿的草原

梅納德·史密斯（John Maynard Smith）與普萊斯（George R. Price）在 1973 年的論文中，把這個問題化簡成一個可以計算的模型。後來的教科書把它整理成大家熟悉的鷹鴿博弈。

族群裡只有兩種策略：

- **鷹派（Hawk）**：一律升級衝突，打到贏或受傷為止。
- **鴿派（Dove）**：只做威嚇展示，對手一升級就立刻退讓。

兩個個體爭奪一份價值為 $V$ 的資源，輸掉打鬥的一方要付出受傷代價 $C$。這裡的「價值」與「代價」都以適存度為單位，也就是對未來繁殖成功的影響。

四種相遇的平均收益如下：

| 我方 \ 對手 | 鷹派 | 鴿派 |
| --- | --- | --- |
| 鷹派 | $(V-C)/2$ | $V$ |
| 鴿派 | $0$ | $V/2$ |

兩隻鷹相遇時，各有一半機會贏得 $V$，也各有一半機會受傷付出 $C$。鷹遇到鴿，鴿立刻退走，鷹獨得 $V$。兩隻鴿相遇時互相展示，最後隨機由一方取得資源，平均各得 $V/2$。

# 三、機制：沒有任何一種策略能永遠獨大

先看全是鴿派的族群。這時出現一隻鷹，牠每次相遇都拿到 $V$，而周圍的鴿只拿到 $V/2$。鷹的收益高出一倍，所以鷹會擴散，全鴿族群並不穩定。

再看全是鷹派的族群。每個鷹的平均收益是 $(V-C)/2$。如果受傷代價大於資源價值，也就是 $C > V$，這個數字是負的。這時出現一隻鴿，牠每次都退讓，收益是 $0$，反而高於周圍的鷹。鴿會擴散，全鷹族群同樣不穩定。

兩個極端都守不住，族群只能停在中間某處。這個「中間」就是演化穩定策略的核心。

**演化穩定策略（Evolutionarily Stable Strategy, ESS）** 的意思是：當整個族群都採用某個策略時，任何少量出現的其他策略都無法得到更高的收益，因此無法入侵。它不要求這個策略讓族群整體最好，只要求它在天擇下守得住。

# 四、必要的數學：複製者動態

1978 年，泰勒（Peter D. Taylor）與容克（Leo B. Jonker）把 ESS 寫成一條動態方程式，後來被稱為複製者動態。核心想法很直接：哪種策略的收益高於族群平均，它在族群中的比例就成長。

令 $p$ 為族群中鷹派的比例。鷹派與鴿派的期望收益分別是：

$$f_H = p\,\frac{V-C}{2} + (1-p)\,V$$

$$f_D = (1-p)\,\frac{V}{2}$$

族群平均收益為 $\bar f = p f_H + (1-p) f_D$。複製者方程式寫成：

$$\frac{dp}{dt} = p\,(f_H - \bar f) = p\,(1-p)\,(f_H - f_D)$$

把收益代入後化簡：

$$f_H - f_D = \frac{V - pC}{2}$$

$$\frac{dp}{dt} = \frac{1}{2}\,p\,(1-p)\,(V - pC)$$

這條方程式有三個靜止點：$p = 0$、$p = 1$，以及 $p^* = V/C$。

當 $C > V$ 時，若 $p < V/C$，括號內為正，鷹派比例上升；若 $p > V/C$，括號內為負，鷹派比例下降。所以只要初始族群裡同時有鷹和鴿，比例就會被拉回 $V/C$。這個內部平衡點就是鷹鴿博弈的 ESS。

當 $V \ge C$ 時，括號內在 $0 < p < 1$ 範圍裡都不小於零，鷹派會一路成長到 $p = 1$。資源值得冒受傷的風險，全面開打就是穩定結果。

舉個數字：若 $V = 2$、$C = 6$，穩定點是 $p^* = 1/3$，族群裡大約三分之一的相遇者會選擇升級衝突。

還有一個值得停下來想的結果。在 $C > V$ 的穩定點上，族群平均收益是 $\frac{V}{2}\left(1 - \frac{V}{C}\right)$，低於全員鴿派時的 $V/2$。天擇找到的平衡並不是對大家最好的安排，它只是任何個體都沒有動機單方面偏離的安排。

# 六、從模型回到動物

鷹鴿博弈預測了一件可以檢驗的事：受傷代價越高，升級衝突的頻率越低。持有致命武器的物種，例如帶毒牙的蛇或長有利角的有蹄類，更常見到儀式化的對峙，這與模型的方向一致。

梅納德·史密斯在 1982 年的專書中進一步加入了更多策略。例如「布爾喬亞」（Bourgeois）策略：若自己是領域主人就當鷹，若是闖入者就當鴿。這種以不對稱線索決定行為的條件策略，能讓族群幾乎完全避免升級打鬥，而且同樣是 ESS。蝴蝶爭奪陽光斑點時，常見到先佔者獲勝的現象，這類觀察常被拿來與這個策略對照。

# 七、科學邊界

這個模型很簡潔，也因此有清楚的適用範圍：

1. **無限大族群與隨機配對**：複製者動態是決定性方程式，假設族群無限大、個體隨機相遇。真實族群有限，會有隨機漂變；有空間結構時，鄰居之間反覆相遇，結果可能明顯改變。
2. **混合族群與混合策略**：$p^* = V/C$ 可以理解為族群中有 $V/C$ 比例的個體是鷹派，也可以理解為每個個體以 $V/C$ 的機率當鷹。這兩種詮釋在 ESS 的靜態分析中等價，但在動態與遺傳機制上不完全相同。
3. **V 與 C 難以量測**：野外很難把資源價值與受傷代價換算成同一個適存度單位，所以模型多用來解釋趨勢，而不是預測精確的比例。
4. **對稱假設**：基本模型假設雙方體型與能力相同。真實動物常依體型、經驗或領域歸屬來評估對手，這類不對稱需要更豐富的模型處理。
5. **模擬器的簡化**：互動模擬以四階龍格-庫塔法積分上述方程式，時間單位是相對值，不對應任何特定物種的世代長度。

鷹鴿博弈留給我們的啟示並不浪漫：點到為止並非出於善意，而是因為在代價夠高的世界裡，全力開打划不來。族群最後停在哪裡，取決於 $V$ 與 $C$ 這兩個數字的比值。
